Amazon Transparency

Features

🔍 Auto-Detection

Identifies items needing codes via [TP], [SN], [SN2] tags in product name.

📱 Barcode Scanning

Works with any USB/Bluetooth scanner. No copy-paste needed.

🎯 Per-Item Tracking

Each line item tracks independently. Multi-SKU orders show separate badges.

✅ Progress Badges

Gray (0), Orange (partial), Green (complete). Visible at a glance.

⛔ Ship Block

Prevents labels until all codes scanned. Zero compliance errors.

📄 Flat File Export

One-click export. Handles split shipments, carriers, and bulk orders.

Scanning Workflow

Click badge→ Scan code(s)→ Enter ↵ Upload→ Auto-advance→ Scan next→ ⋯ repeat
Pro tip: Program scanner to send Enter after each scan. Never touch the mouse.
