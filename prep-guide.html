Prep Guide

Set up your Veeqo products and install the extension in under 5 minutes.

Before You Start

The Code Scanner reads product names in Veeqo to detect which items need codes. Tag your products first.

What You Need

  • Google Chrome browser (desktop)
  • Veeqo account with API access
  • The extension folder (from your Amazon rep)
  • USB or Bluetooth barcode scanner (recommended)
  • Products tagged with [TP] or [SN] in Veeqo

Step 1: Tag Your Products

Add the code type tag to the END of each product name

If item needs...Add this tagExample
Transparency codes[TP]Nexen Aria AH7 Tire (205/65R16, 95H) [TP]
Serial numbers (1/unit)[SN]DJI Mini 4 Pro Drone [SN]
Serial numbers (2/unit)[SN2]iPhone 16 Pro Max [SN2]
Where to add: Veeqo → Inventory → Find product → Edit → Product Title. Tag must be in the title.

Step 2: Get Your API Key

Go to app.veeqo.com → Settings → Users

Log in and navigate to Users section

Click "Add New User"

Name it Code Scanner

Copy the API key

Save it — you'll paste it into the extension

Step 3: Install the Extension

Save extension folder permanently

Desktop or Documents — don't delete it later

Open chrome://extensions

Turn ON "Developer mode" (top-right)

Click "Load unpacked" → select folder

Extension icon appears in toolbar

Click icon → paste API key → Save

Reload Veeqo tab — badges appear!

Step 4: Verify

Go to Veeqo → Orders. You should see:

  • Orange TP: 0/1 badges on [TP] items
  • Purple SN Required tags on [SN] items
  • Export Codes button in the nav bar
No badges? Check: product name has tag, extension enabled, Veeqo tab reloaded.

FAQ

Q: Do I tag every product?

Only Transparency-enrolled or serial-tracked items. Untagged items are ignored.

Q: Handheld scanner work?

Yes — any USB/Bluetooth scanner sending keyboard input works.

Q: Wrong code scanned?

Click × next to any code in the modal before uploading.

Q: Works on mobile?

No — desktop Chrome only.

Q: Multiple staff?

Yes — each installs with same API key. Badges refresh from live data.
