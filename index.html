Privacy Policy

Veeqo Code Scanner Chrome Extension

Last Updated: July 27, 2026

Overview

This privacy policy describes how the Veeqo Code Scanner Chrome extension ("the Extension") collects, uses, and shares user data. We are committed to protecting your privacy and being transparent about our data practices.

In short: We store your API key locally on your device. We send it only to Veeqo's API. We collect nothing else. We share nothing with anyone else.

How We Use Your Data

Your Veeqo API key is used exclusively to:

  • Authenticate requests to the Veeqo API (api.veeqo.com) to read order data
  • Update order line items with scanned Transparency and Serial Number codes
  • Enable flat file export functionality by reading shipment details

Your API key is never used for any other purpose.

No additional permissions are requested. The extension does not access browsing history, other tabs, downloads, bookmarks, or any other Chrome APIs.

Data Retention

  • Your API key remains in Chrome local storage until you manually remove it or uninstall the extension
  • No order data is cached or persisted between browser sessions
  • Uninstalling the extension removes all stored data automatically
  • Flat file exports exist only on your local device after download

Your Rights

  • View: Click the extension icon at any time to see your stored API key
  • Delete: Remove the API key from the extension popup, or uninstall the extension entirely
  • Revoke access: Delete the "Code Scanner" user in your Veeqo account settings to invalidate the API key
  • Portability: Your API key is the only stored data — it can be transferred by simply entering it on another device

Children's Privacy

This extension is designed for use by Amazon sellers managing business operations. It is not directed at children under 13 and does not knowingly collect data from children.

Changes to This Policy

If we make changes to this privacy policy, we will update the "Last Updated" date at the top of this page. Continued use of the Extension after changes constitutes acceptance of the updated policy.
